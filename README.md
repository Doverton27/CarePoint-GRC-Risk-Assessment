# CarePoint Health Services — GRC Risk Assessment

## Project Overview

This project is a simulated Governance, Risk, and Compliance (GRC) assessment for a fictional healthcare organization called CarePoint Health Services.

The purpose of this project was to gain hands-on experience identifying cybersecurity risks, evaluating security controls, reviewing compliance evidence, and documenting remediation recommendations using the NIST Cybersecurity Framework (NIST CSF).

## Project Objectives

- Identify and classify critical organizational assets.
- Assess cybersecurity risks based on likelihood and impact.
- Develop a risk register to document identified risks.
- Map security controls to NIST CSF functions.
- Review simulated security control evidence.
- Identify control gaps and recommend remediation.
- Prepare a final GRC assessment report for management.

## Framework Used

**NIST Cybersecurity Framework (NIST CSF 2.0)**

The assessment primarily focused on the Protect function, including identity management, access control, security awareness, data protection, and secure configuration.

## Key Findings

The simulated assessment identified several security and compliance gaps:

- Incomplete user access review documentation.
- Missing security awareness training records.
- Delayed termination of former employee accounts.
- Lack of documented Azure configuration reviews.
